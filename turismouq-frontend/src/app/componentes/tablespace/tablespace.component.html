Pilar 01

Aislamiento Físico de I/O y Rendimiento OLTP

Las operaciones de reserva continua realizan operaciones DML de alta frecuencia (INSERT, UPDATE, SELECT FOR UPDATE). Al segregar las 25,000 reservas, consumos de servicios y pagos en un tablespace físico independiente, las consultas analíticas pesadas (como PIVOT, ROLLUP y RANK) no saturan el buffer cache ni compiten por los mismos bloques de disco que las transacciones de los usuarios en tiempo real.

Cero contención de buffer cache Canales de I/O independientes
🛡️
Pilar 02

Políticas Diferenciadas de Backup & Modo READ ONLY

El tablespace primario USERS requiere copias de seguridad incrementales diarias mediante Oracle RMAN debido a su constante mutabilidad. En contraste, TBS_HISTORICO_RESERVAS almacena períodos cerrados que pueden sellarse con: ALTER TABLESPACE TBS_HISTORICO_RESERVAS READ ONLY; Esto reduce drásticamente el tamaño y la ventana horaria requerida para los backups de la base de datos institucional.

Ventanas de backup 80% más rápidas Inmunidad ante escrituras no autorizadas
🗜️
Pilar 03

Gestión del Ciclo de Vida (ILM) & Compresión Avanzada

Permite habilitar compresión avanzada de datos relacionales en Oracle (COMPRESS FOR OLTP o QUERY HIGH) específicamente sobre el datafile de reservas históricas, logrando reducciones de espacio de hasta un 70% en disco. Asimismo, permite reubicar físicamente el archivo .DBF hacia unidades de almacenamiento secundario de bajo costo sin afectar las tablas maestras.

Ahorro de disco de hasta 70% Tiering en almacenamiento secundario

Consultas DBA de Inspección en Tiempo Real 
-- 1. Verificación de cuotas y estado del Tablespace
SELECT tablespace_name, status, extent_management, allocation_type, segment_space_management
FROM user_tablespaces
WHERE tablespace_name = 'TBS_HISTORICO_RESERVAS';

-- 2. Consumo de bytes y extensiones por segmento físico
SELECT segment_name, segment_type, bytes, ROUND(bytes/1048576, 2) AS MB, extents
FROM user_segments
WHERE tablespace_name = 'TBS_HISTORICO_RESERVAS'
ORDER BY bytes DESC;

-- 3. Distribución de tablas y volumen de registros por tablespace
SELECT table_name, tablespace_name, num_rows
FROM user_tables
ORDER BY tablespace_name DESC, table_name ASC;
